# 💰 Dashboard Executivo Financeiro

## Objetivo

Dashboard desenvolvido para análise dos principais indicadores financeiros, permitindo acompanhar receitas, lucros, impostos, comissões e desempenho comercial.

## Tecnologias

- Power BI
- DAX
- Power Query
- SQL
- Python

## Indicadores

- Receita Bruta
- Receita Líquida
- Lucro Total
- Comissão Total
- Ticket Médio
- Clientes Atendidos
- Receita por Loja
- Receita por Produto
