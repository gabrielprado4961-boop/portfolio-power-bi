# 📈 Dashboard Executivo de Vendas

## Objetivo

Dashboard desenvolvido para análise comercial, permitindo acompanhar vendas, custos, lucratividade, metas e desempenho dos produtos, lojas e departamentos.

## Tecnologias

- Power BI
- DAX
- Power Query
- SQL
- Python

## Indicadores

- Valor Total de Vendas
- Quantidade Vendida
- Custo Total
- Lucro Bruto
- Margem (%)
- Evolução Mensal das Vendas
- Resultado Anual x Meta
- Quantidade Vendida por Loja
- Acumulado Móvel de Vendas
- Participação por Perfil de Idade
- Melhor Dia de Venda por Ano
- Preço Médio e Mediana por Departamento
- Quantidade Vendida por Cidade e Departamento
