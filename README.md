# 📊 Portfólio de Projetos em Power BI

Bem-vindo ao meu portfólio!

Este repositório reúne projetos desenvolvidos com foco em **Business Intelligence** e **Análise de Dados**, aplicando técnicas de modelagem dimensional, criação de indicadores (KPIs), DAX, Power Query e visualização de dados para apoiar a tomada de decisão.

# 🚀 Projetos

## 👥 Dashboard Executivo de RH

Dashboard desenvolvido para análise dos principais indicadores de Recursos Humanos.

**Principais indicadores**
- Total de Funcionários
- Homens e Mulheres
- Média de Treinamentos
- Classificação de Performance
- Salário Médio
- Horas Extras
- Faixa Etária
- Tipo de Contrato

---

## 💰 Dashboard Executivo Financeiro

Dashboard voltado para análise financeira e acompanhamento dos principais indicadores de desempenho.

**Principais indicadores**
- Receita Bruta
- Receita Líquida
- Lucro Total
- Comissão Total
- Ticket Médio
- Impostos
- Clientes Atendidos

---

## 📈 Dashboard Executivo de Vendas

Dashboard para análise comercial, permitindo acompanhar vendas, custos, metas e desempenho ao longo do tempo.

**Principais indicadores**
- Valor Total de Vendas
- Quantidade Vendida
- Custo Total
- Lucro Bruto
- Margem %
- Evolução das Vendas
- Metas
- Quantidade por Loja
- Análises por Produto e Cidade
